## 🚀 Local Development & Deployment

### Quick Start
```bash
# 1. Clone repository
git clone https://github.com/soham-10-byte/findable.git
cd findable

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

### Static Build
```bash
# Type check and build static HTML to /dist
npm run build
```

### One-Click Deploy to Vercel
1. Import `soham-10-byte/findable` into [Vercel](https://vercel.com/new).
2. Set Environment Variable:
   ```env
   PUBLIC_WEB3FORMS_KEY=ebef1c21-5ed9-41dc-9759-e9ec5331e8fa
   ```
3. Click **Deploy**.
